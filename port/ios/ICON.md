# Halo: CE app icon

The app icon is the Halo ring artwork supplied by the user on 2026-09-30
(969 × 955 JPEG). It was made square by repeating the textured background's
top and bottom rows for 7 pixels each (so none of the ring is cropped), then
resized with Lanczos filtering to the opaque 1024-pixel `Icon-Artwork.png`.
`Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png` is that image, and the
smaller device sizes are Lanczos resizes of it. iOS applies the rounded-square
mask at display time, so there are no baked-in borders or transparent corners.
